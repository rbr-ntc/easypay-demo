# EasyPay

Заказ и оплата в ресторане по QR с привязкой блюд к персонам **в момент заказа**
(а не делением готового счёта постфактум). Надстройка над кассой ресторана (iiko / R-keeper).

**Стадия**: PRD и архитектура готовы, работает живое демо
(http://77.221.141.238). Продакшн-части — касса, эквайринг, БД — ещё нет.

## Ключевые решения (зафиксированы)

- **MVP-канал**: web-app (PWA) по QR, без установки. Планшет — фаза 2, нативка — фаза 3.
- **Поток гостя**: меню без барьера → имя+зверь при первом блюде → корзина (своё крупно +
  свёрнутый «весь стол») → отправка на кухню (своё / за весь стол) → статус → оплата в конце.
- **Касса — источник истины**; все мутации через PosAdapter с идемпотентными ключами.
- **СБП — приоритетный способ оплаты** (экономия 0,7–1,8 п.п. на транзакции).
- **Чаевые — напрямую официанту** (не через счёт ресторана).
- **Аватары персон — зверюшки** (иллюстрации, не эмодзи).
