# Промт для презентации EasyPay

Документ-источник для генерации презентации в любом инструменте (Gamma, Tome, Pitch, Claude,
PowerPoint/Keynote, pptx-skill). Структура слайдов и весь контент зафиксированы — визуальный стиль
ты выбираешь сам (плейсхолдеры `{{...}}`).

> ⚠️ Все цифры — это публичные бенчмарки рынка и заявления вендоров (Sunday, нетмонет), а не наш
> аудит. На слайдах подаём их как ориентир/«по данным рынка», а не как наши гарантии. Источники
> подписаны мелким шрифтом на каждом слайде.

---

## 0. Как пользоваться

1. Подставь визуальный стиль в блок «Стиль презентации» (один раз).
2. Ниже — 14 слайдов: для каждого задан **заголовок, ключевое сообщение, контент, визуал**.
3. Копируй целиком в генератор презентаций. Сквозной нарратив: Проблема → Решение → Чем мы лучше →
   Цифры → Деньги → Рынок → Демо → План → CTA.
4. Демо-скриншоты подставляются из макетов (см. `docs/design-prompt.md`).

## Стиль презентации (подставь свой)

```
ТОН: уверенный, «продуктовый», для презентации ресторанам/инвесторам. Минимум текста на слайде,
     крупные цифры, воздух, 1 мысль = 1 слайд.
АУДИТОРИЯ: владельцы ресторанов / управляющие сетей (основная), инвесторы (вторая).
ЯЗЫК: русский. Валюта ₽.

ВИЗУАЛ (подставить):
- Палитра / бренд-цвет: {{BRAND}}
- Акцент для цифр-метрик: {{ACCENT}}
- Шрифт заголовков / текста: {{FONT}}
- Стиль: {{минимализм / премиум-ресторан / бодрый стартап}}
- Фон: {{светлый / тёмный}}
- Иконки/иллюстрации: {{стиль}}
- Скриншоты приложения в рамке телефона (mockup) — да.

ПРИНЦИП ЦИФР: каждая метрика — ОДНА огромная цифра + короткая подпись + источник мелким.
```

## Слайд 1 — Титул

```
ЗАГОЛОВОК: EasyPay
ПОДЗАГОЛОВОК: Оплата заказа по QR с привязкой блюд к персоне.
            Каждый платит ровно за своё — без споров и очереди к терминалу.
ВИЗУАЛ: фон-фото ресторана/стола; рамка телефона с экраном «Корзина по персонам».
СНОСКА: логотип, слоган «Scan. Split. Pay в 30 секунд».
```

## Слайд 2 — Проблема

```
ЗАГОЛОВОК: Закрытие счёта — самое узкое место вечера
КЛЮЧ: 5 болей ресторана, которые тормозят оборот и режут выручку.
КОНТЕНТ (иконки + короткая строка):
- ⏳ Гости ждут счёт и терминал в час пик → стол простаивает.
- 🧮 Официант вручную делит счёт на калькуляторе и терминале.
- 🤬 Споры «кто что заказывал».
- 💳 Чаевые падают при безналичной оплате.
- 📉 Высокая комиссия эквайринга — до 2,5%.
ВИЗУАЛ: «было» — усталый официант с терминалом / очередь.
```

## Слайд 3 — Решение

```
ЗАГОЛОВОК: Гость платит сам — со своего телефона
КЛЮЧ: QR на столе → меню → выбрал себя → оплатил своё → чек и отзыв. Без установки приложения.
КОНТЕНТ (3 иконки):
- 📷 Сканирует QR на столе — открывается web-app, ничего не нужно ставить.
- 🍽 Каждое блюдо закреплено за персоной ещё при заказе.
- ⚡️ Оплата по СБП/карте + чаевые официанту за ~30 секунд.
ВИЗУАЛ: телефон с экраном входа/меню.
СНОСКА: «No app to download».
```

## Слайд 4 — Наше отличие (УТП) ⭐

```
ЗАГОЛОВОК: Мы делим счёт ДО заказа, а не после
КЛЮЧ: главный дифференциатор. Конкуренты режут уже готовый счёт постфактум — мы закрепляем
     блюдо за персоной в момент заказа.
КОНТЕНТ (две колонки сравнения):
  ОНИ (нетмонет, SberFood, даже Sunday):
    «Отметь свои позиции» из общей корзины ПОСЛЕ оплаты-этапа → споры, ошибки.
  МЫ (EasyPay):
    Блюдо привязано к персоне СРАЗУ → точный личный счёт, ноль споров,
    аналитика «кто что ест».
ВИЗУАЛ: разделённый экран «после» vs «сразу», цветные аватары персон.
```

## Слайд 5 — Как это работает

```
ЗАГОЛОВОК: 4 шага гостя
КОНТЕНТ (горизонтальный таймлайн):
  1. Сканирует QR → видит стол №12.
  2. Выбирает себя (🟣 Анна) или добавляет нового гостя.
  3. Заказывает / открывает свой счёт — блюда уже за ним.
  4. Платит своё по СБП + чаевые → чек на телефон.
ВИЗУАЛ: 4 мини-скриншота телефона по шагам.
СНОСКА: «работает поверх вашей кассы — iiko или R-keeper».
```

## Слайд 6 — Цифры выгоды (главный слайд) 🔥

```
ЗАГОЛОВОК: Что это даёт ресторану
КЛЮЧ: 4 крупные метрики, каждая — отдельным блоком.
КОНТЕНТ (сетка 2×2, огромные цифры):
  +15%   оборачиваемость столов
         (кейс нетмонет на iiko; Sunday: «serve 15% more guests»)
  +12%   средний чек
         (Sunday «increase basket size by 12%» за счёт цифрового меню и допродаж)
  ~12%   средний размер чаевых от суммы заказа
         (по данным «Нетмонет»/Альфа-Банк, 2026)
  85%    гостей оставляют отзыв
         (бенчмарк Sunday)
ВИЗУАЛ: крупные числа цветом {{ACCENT}}, иконки.
СНОСКА: «Метрики — публичные данные вендоров и кейсы рынка 2025–2026, ориентир для пилота».
```

## Слайд 7 — Экономика: СБП вместо дорогого эквайринга 💰

```
ЗАГОЛОВОК: Комиссия в 3–5 раз ниже
КЛЮЧ: СБП — способ оплаты по умолчанию в нашем UI. Прямая экономия на каждой транзакции.
КОНТЕНТ (сравнение-бар):
  Классический эквайринг: ~2,5%  (в среднем; карты 1,2–1,5%+)
  СБП через EasyPay:      0,4–0,7%
  → Экономия 0,7–1,8 п.п. с КАЖДОГО рубля оборота по QR.
ПРИМЕР: при обороте 3 млн ₽/мес и 30% оплат через СБП — экономия ≈ 8–16 тыс ₽/мес.
ВИЗУАЛ: два столбца-бара, стрелка экономии.
СНОСКА: «Ставки СБП — данные НСПК; зависят от MCC и банка».
```

## Слайд 8 — Скорость

```
ЗАГОЛОВОК: Оплата за 30 секунд
КЛЮЧ: меньше трения = выше оборот и чаевые.
КОНТЕНТ:
  «Scan, split, and pay in 30 seconds» — «10 секунд: оплатить, чаевые, отзыв, чек».
  Экономия до 12 минут на транзакцию обслуживания (бенчмарк Sunday).
ВИЗУАЛ: секундомер / прогресс 30s, скриншот success-экрана.
```

## Слайд 9 — Рынок и доказательство

```
ЗАГОЛОВОК: Модель уже работает в мире и в России
КОНТЕНТ:
  🌍 Sunday — 3 500 ресторанов (Lettuce Entertain You, Tao Group), основатели из Big Mamma.
  🇷🇺 нетмонет (Альфа-Банк), CloudTips, SberFood/Plazius, Tapper — рынок сформирован.
  НИША, которую никто не закрыл: привязка блюд к персоне В МОМЕНТ ЗАКАЗА.
ВИЗУАЛ: логотипы-плашки + выделенная «свободная ниша».
```

## Слайд 10 — Демо приложения

```
ЗАГОЛОВОК: Как выглядит для гостя
КОНТЕНТ: галерея из 3–4 ключевых экранов в рамках телефона:
  Выбор персоны · Корзина по персонам · Оплата (СБП приоритет) · Чек + отзыв.
ВИЗУАЛ: скриншоты из макетов (docs/design-prompt.md).
```

## Слайд 11 — Совместимость и закон

```
ЗАГОЛОВОК: Встаёт поверх вашей кассы, без рисков по 54-ФЗ
КОНТЕНТ (иконки-чек):
  ✅ Интеграция с iiko и R-keeper — касса остаётся источником истины.
  ✅ Фискализация через вашу кассу/ОФД — без двойных чеков.
  ✅ Чаевые напрямую официанту — без НДФЛ/взносов на ресторан.
  ✅ СБП, карты, кошельки (T-Pay/SberPay/Mir Pay).
ВИЗУАЛ: логотипы iiko / R-keeper / СБП / ОФД.
СНОСКА: «Соответствие 54-ФЗ; финальную схему фискализации фиксируем под вашу кассу/эквайер».
```

## Слайд 12 — Дорожная карта

```
ЗАГОЛОВОК: Запуск поэтапно
КОНТЕНТ (3 фазы-колонки):
  MVP: оплата по QR с привязкой к персонам, СБП+карта, чаевые, web-app гостя.
  Фаза 2: заказ через приложение, планшет на столе, деление общих блюд, аналитика.
  Фаза 3: глубокий раздельный расчёт в кассе, сети/фудкорты, лояльность, ИИ-допродажи.
ВИЗУАЛ: дорожка из 3 вех.
```

## Слайд 13 — Монетизация (для инвестор-версии; для ресторана — «Сколько стоит»)

```
ЗАГОЛОВОК: Модель
КОНТЕНТ:
  - SaaS-подписка с точки/мес.
  - % с транзакции / маржа на эквайринге.
  - Платная аналитика и маркетинг-модули.
  - Базовые чаевые бесплатно для заведения (платит гость) — модель нетмонет.
ВИЗУАЛ: 3–4 плитки источников дохода.
```

## Слайд 14 — Призыв к действию

```
ЗАГОЛОВОК: Запустим пилот в вашем ресторане
КЛЮЧ: один зал, 2 месяца, измеряем оборачиваемость / долю QR / чаевые.
КОНТЕНТ: «Поставим поверх вашей iiko/R-keeper за {{X}} дней. Платите меньше комиссии
         с первого дня». Контакты, QR на демо/лендинг.
ВИЗУАЛ: крупный CTA, бренд-цвет, контактные данные.
```

## Приложение — банк проверенных цифр (для подписей и Q&A)

| Метрика | Значение | Источник |
|---|---|---|
| Оборачиваемость столов | +15% | кейс нетмонет (iiko, Multibit); Sunday |
| Средний чек / корзина | +12% (до 10–20%) | Sunday |
| Средний размер чаевых | ~12% от заказа | «Нетмонет»/Альфа-Банк, vc.ru, 2026 |
| Средний чек чаевых 14.02.2026 | 506 ₽ (+42% г/г) | СИА |
| Доля оставивших отзыв | ~85% | Sunday |
| Экономия времени | до 12 мин/транзакция | Sunday |
| Скорость оплаты | 30 сек (10 сек на оплату+чаевые+отзыв+чек) | Sunday |
| Масштаб Sunday | 3 500 ресторанов | Restaurant Business Online, 2025 |
| Комиссия СБП C2B | 0,4–0,7% (0,2% ЖКХ) | НСПК |
| Эквайринг (карты) | ~2,5% средн.; от 1,14–1,5% | тарифы банков 2025–2026 |

> Правило для слайдов: маркетинговые цифры подаём как «по данным рынка / вендоров», свои —
> только после пилота. Это защищает от завышенных ожиданий клиента.
