# Фотографии блюд — происхождение и лицензии

Снимки подобраны через [Openverse](https://openverse.org) с фильтром по лицензиям,
разрешающим коммерческое использование и переработку (CC0 и CC BY). Кадрированы
под 4:3 и ужаты до 900×675 — это переработка, которую обе лицензии допускают.

**Что это не покрывает.** CC BY требует указания автора *в самом продукте*, а не только
в репозитории. Для демо-стенда файла достаточно, для публичного запуска нужен либо
видимый блок атрибуции на экране меню, либо покупная фотосъёмка (Shutterstock, Depositphotos)
либо собственная съёмка заведения. Это решение продукта, не разработки.

Шесть снимков — `duck`, `margarita`, `padthai`, `springrolls`, `steak`, `tomyam` —
лежали в репозитории до этой подборки, их происхождение здесь не зафиксировано.

Блюда без фотографии показываются компактной строкой без картинки — это предусмотрено
макетом, а не поломка: хумус, салат с тунцом, дорадо, котлета по-киевски, наполеон,
медовик, лазанья, вода, облепиховый чай.
